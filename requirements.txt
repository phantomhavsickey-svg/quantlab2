# IMPORTANT - install torch separately FIRST:
#   1) pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
#   2) pip install -r requirements.txt
#
# Why cu121:
#   - This machine's NVIDIA driver is 537.53, which supports CUDA runtime
#     up to 12.1 -> must use cu121 wheels.
#   - torch 2.5.1 is the last release with cu121 wheels (2.6+ ships only
#     cu118/cu124/cu126).
#   - cu124 requires driver >= 551.61. After upgrading the driver:
#       pip install torch --index-url https://download.pytorch.org/whl/cu124
#   - Verify:
#       python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
#
# If download.pytorch.org is too slow (e.g. from China), download the
# wheel directly from the SJTU mirror (resumable with curl -C -):
#   curl -L -C - -o torch-2.5.1+cu121.whl ^
#     "https://mirror.sjtu.edu.cn/pytorch-wheels/cu121/torch-2.5.1%2Bcu121-cp311-cp311-win_amd64.whl"
#   pip install torch-2.5.1+cu121.whl --index-url https://pypi.tuna.tsinghua.edu.cn/simple
# (mirrors.aliyun.com/pytorch-wheels/cu121 does NOT host this wheel)
